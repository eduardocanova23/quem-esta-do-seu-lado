# docs/decisoes/

Os ADRs (Architecture Decision Records): uma decisão cara de reverter por arquivo.

- Nome: `NNNN-titulo.md`, numeração sequencial com quatro dígitos (`0001-forma-de-entrega-do-site.md`).
- Seções: contexto, opções, critérios com peso, decisão, consequências e quando revisitar.
- ADR aceito não se edita: uma decisão nova gera outro ADR, que diz qual substitui.

O ADR 0001 trata do ambiente Python. O próximo da lista do método é o da forma de entrega do site.
