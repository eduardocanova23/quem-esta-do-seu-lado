# docs/

O texto que vem antes do código: requisitos, decisões, modelo de dados, design e procedimentos. O Claude lê estes arquivos no começo das sessões; você lê o código contra eles.

- `metodo.md`: o método de construção do projeto.
- `estado.md`: passagem de sessão quando uma tarefa para no meio.
- `produto/`, `decisoes/`, `dados/`, `design/`, `arquitetura/`, `runbooks/`: cada pasta tem o próprio README.

Regra: doc muda no mesmo PR do código que ele descreve.
